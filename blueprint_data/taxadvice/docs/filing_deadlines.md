# Filing deadlines and extensions

Individual income tax returns are generally due in mid-April. An automatic six-month extension to file can be requested by the original deadline, but an extension to file is not an extension to pay: estimated tax owed is still due in April to avoid interest and penalties.

Estimated quarterly payments apply when income is not subject to withholding, such as self-employment. Missing a quarterly payment can add an underpayment penalty even if the annual return is filed on time.
